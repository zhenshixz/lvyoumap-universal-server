# 景点补图工作台（仅 Beta）

双击根目录的 `gallery_batch.bat`。它检查依赖、复用或启动网页服务，并显示本机与局域网地址；关闭 BAT 窗口不会停止服务。旧的01/02/03入口已归档。

1. **生成新批次清单**：设置任意大于0的条数（默认10），选择尚未处理或之前网络失败的景点；超过当前剩余量时生成全部。生成不会启动采集，历史清单和已填写链接保留，可切换回来。
2. **填写并保存**：保存即确认这些Trip地址，不再做名称启发式阻断。可留空、可跳过；修改未保存时不能启动。已保存的同内容清单不重复创建版本。
3. **启动采集**：网页启动后台程序，已完成的同清单直接打开原批次；中断的同清单继续原批次。进度每3秒刷新，批次按北京时间命名。运行期间请求Windows保持唤醒，任务结束释放。
4. **预览与写入**：默认勾选所有机器筛选合格图，可取消图片、指定封面。点击“写入 Beta”就是验收确认，所写景点暂时不再补图，无需再点一次确认。1–5张均可写入；0张或未选择的景点不更改原图。

新清单排除已写入图库、正在采集、等待验收、已被其他未运行清单占用的景点。无图/失败项目只在选择重试条件时出现。原全国任务的待验收候选也不会混入新清单。

## 写入与恢复

仅写当前批次所选图片到 `content/attraction-gallery-overrides.json`，使用原始图片HTTPS地址，保留Trip详情页等真实来源。不会将审图缓存路径写入内容。其余景点不改，不要求自动采集的全局3张门槛。

每批保存 `approval.json`、`apply.json`、`apply.log` 和 `apply-backup/`。写入前备份图库和data；构建先生成 `.dist-next`，核对景点封面与图片顺序后才切换dist。失败恢复原数据；进程意外终止时显示恢复入口，重试先恢复备份。成功回执标记景点暂不补图，重复点击不会再写入。

局域网只读。保存、生成、启动、写入仅允许本机网页；后台任务互斥，采集中不允许写入。正式仓始终不在工作台操作范围。

## 图源与缓存

Trip支持attraction及shops详情链接。SHOP使用页面“全部相片”的SearchPoiImageInfo接口，只请求第一页，最多下载前5张并沿用相同筛选；此前因unsupported_layout跳过的项目，再次启动原清单可只补跑该Trip来源。

Trip每页最多取5张图库图片，长边至少1000、短边至少560，并做过暗检测、感知哈希去重。高德可用时只取精确POI返回第一张，长边至少1280、短边至少720。

2026年9月高德基础搜索月配额已耗尽。`.runtime/gallery-link-batches/source-policy.json` 暂停高德至2026-10-01 00:05（北京时间），期间无探测和POI请求，空Trip地址可能得到0张。到期解除本地停用策略；是否实际恢复以高德接口额度为准。

每批隔离文件在 `.runtime/gallery-link-batches/runs/<时间-批次ID>/`；原图处理成功后清理raw，保留候选与小缩略图供验收。历史清单在 `.runtime/gallery-link-batches/drafts/`。不自动清除待验收批次，不删除线上依赖图片。


## 2026-09-11 自动搜索模式

- 使用根目录 gallery_batch.bat，网页生成清单后可直接点“自动搜索并采集 / 续跑”。手填修改必须先保存；已保存链接优先使用，空地址才搜索，勾选跳过不采集。
- 本地 Puppeteer 控制独立无头 Chrome/Edge，单浏览器串行搜索，不需要逐项调用对话模型。独立配置位于 .runtime/gallery-link-batches/trip-search-profile，关闭网页不影响后台任务。
- 同时提取 attraction 与 shops 卡片，以简繁转换、空白/标点归一后的完整名称和城市匹配；遇同名异地，额外用“城市＋原名”搜索。不同名字、多个同地域同名结果留给人工，不自动去后缀凑匹配。
- 搜索每次导航25秒、结果等待18秒、最多2次尝试；连续两项服务异常暂停并保留断点。重新点击自动搜索续跑；已成功来源不重下载。网页3秒刷新状态，批次启动互斥。电脑重启后需手动启动BAT并续跑，本版本不承诺无人介入恢复验证码或永久网络故障。

### HTTP 432 与切换 IP 后快速重跑

- Trip 详情页或 SHOP 图库接口一旦遇到 HTTP 432，立即暂停整批，不再请求下一个景点，也不做同一IP的冷却重试；页面提醒切换 IP。切换后点击“我已切换 IP，继续运行”，从当前景点断点继续。
- 批次完成且尚未写入 Beta 时，进度页会显示“切换 IP 后快速重跑 N 个失败项”。切换 IP 后点击即可，只重跑 432、连接超时等临时失败项；成功项、明确无图库项和人工待补项不重复运行。
- 完成后在批次预览验收图片。可点击“将本批无图项转为手填清单”；展开搜索备选页，确认后填入并保存，使用“仅按手填链接采集”。自动发现的候选地址不等于人工确认。
- 搜索缓存仅保存成功映射；批次 state.json 保存搜索原因及少量候选，manual-pending.json 保存无图清单。图片仍走原尺寸与质量筛选，不自动写入Beta。高德本月停用不变。


## 已有图片保护（2026-09-11修正，优先于旧说明）

“写入Beta”只追加所选新图，永远不因本批少选图片而删掉已有图片。验收页分开显示已有图和本批新图；已有图自动保留，不提供补图内删除入口。默认保留当前封面，也可在新旧两区明确选择封面。新增1–5张的限制不包含旧图，总图库可以超过5张。

后端写入时重新读取当前图片，合并去重后核验最终构建，避免其他批次的已验收图被旧页面覆盖。确需删除旧图时必须另行明确授权，不能把“补图”当成整组替换。历史已写批次刷新页面后也会显示当前已有图片，原回执仍保留当时选择的记录。


## 统一待补队列（2026-09-11）

生成清单不再选择“新景点”或“失败景点”：统一“待补景点”，优先未尝试项，再安排网络超时、连接错误等可重试项。已有候选待验收、已写入、其他清单预留及运行中项目不重复入队。

Trip详情已正常取得但无图，或图片已下载且全部不合格：同一详情链接不再采集；名称地域没有匹配结果：不反复自动搜索，保留人工补链接入口。只有换了不同链接才重新尝试该来源。图片没有下载成功的网络失败仍可以重试，不能误当成质量失败。

重新打开或保存旧清单也受同链接保护。未填链接的手动模式如果从未进行自动搜索，仍可首次自动搜索。现有图始终保留，补图分流不改变已验收内容。


## 2026-09-14效率规则

图片按解码后的原始宽度大于540像素即可进入候选，仍执行过暗、重复和解码检查。Trip搜索结果只要城市一致，自动采用搜索顺序第一项；名称差异、原始候选和排名会记录在批次状态，方便追溯。没有同城结果才进入手填。
