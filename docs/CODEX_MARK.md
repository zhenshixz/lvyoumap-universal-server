## 2026-09-07｜图库断点恢复、稳定来源提速与实图初审

### 当前结果与边界

- 仅在 beta 工作，未修改正式 Git、未写入地图图库、未部署；Gemini 文档和前端修改未动。
- 当前仍是跨省 **100 个样本**，不是全国完成。达到 5 张候选图的景点由 20 个增加至 **52 个**，另 **48 个**保留断点。候选暂存 `.runtime/attraction-gallery-batch/state.json`，9 张联系表在该目录的 `contact-sheets` 下。
- 已浏览全部联系表，并新增拒绝 11 个 URL，涉及海报、叠加水印/宣传标识、拼贴与疑似异地图片。拒绝清单累计 12 项。长隆、香港迪士尼、德天等不能为凑数放行。
- `ready_for_user_review` 只表示有 5 张可供进一步验收的候选，不代表逐图原尺寸、真实手机外链加载及实体真实性全部通过。联系表初审不能代替最终地图验收；不得直接全量写入。

### 根因与修复

- 携程旧逻辑泛抓 `imageUrl`、截前两张，容易混入非相册内容。改为解析 `__NEXT_DATA__ → poiDetail → imageInfo.poiPhotoImageList`，核对实体名称，记录页面、POI 和图片 ID；不扫评论、相关推荐图片。
- 省份列表的 `?keyword=` 未形成有效筛选。改为最多 3 页实际列表，复用历史携程/二次补证链接；同页并发请求合并、HTML 缓存 7 天，避免各景点反复下载同一页。
- 备用源触发改为按已通过尺寸检查的图片数，不再按原始链接数量。只对未完成景点执行，有少量候选余量供去重，不重跑已完成图库。
- BAT 与 npm 入口加入 `--repair-pending`；改变批量大小不清空状态，`--max-items` 可限定本轮工作量；按旧断点优先续跑，单项异常不终止整批。
- 状态采用临时文件原子替换；审图文件改用内容哈希命名，恢复时校验哈希，避免旧索引文件被覆盖后显示错图。保留成功的高德缓存；此前未成功取得高德数据的记录允许以后重试。
- 修正 dHash 行索引；保留已筛选结果，记录近似重复/过暗/解码失败原因；命中拒绝清单会重新筛选。
- BAT 保持 ASCII + CRLF，增加路径、脚本及 Python 图片依赖预检，错误保留窗口。

### 验证与后续

- `node scripts/test_gallery_source_parsers.js` 通过：正确实体、错误实体拒绝、仅相册提取、缺失结构拒绝，以及缓存的灵隐寺真实页面 4 张相册图。
- 采集脚本语法检查通过；实际完成两轮仅缺口续补、渲染与实图初审。审图缓存不属于正式部署资源，图片仍保留外链。
- Android User-Agent 下载检查仅代表本机 HTTP 连通，**不等于真实手机/微信可用性验证**。自动尺寸检查也不等于保证清晰、无水印；高德 POI 图片同样可能有海报，不能称为官方审核实景图。
- 下一步只补这 48 个缺口，解决实体页面索引/别名与照片质量问题，再扩大全国；禁止改用搜索引擎或降低质量凑 5 张。
- 抽查候选：白帝城·瞿塘峡景区、万岁山武侠城、南浔古镇、云冈石窟、黄鹤楼。检查 5 张是否均为对应景点、无明显水印和海报、原尺寸清晰；地图及真实手机验收尚未执行。

涉及：`scripts/collect_attraction_galleries_batch.js`、`scripts/gallery_source_parsers.js`、`scripts/test_gallery_source_parsers.js`、`scripts/render_attraction_gallery_batch.py`、`content/attraction-gallery-image-denylist.json`、`run_gallery_batch.bat`、`package.json`。

## 2026-09-04｜全国景点图库稳定来源批处理

## 2026-08-28｜景点内容分层与修复边界

### 三层内容边界

- 基本信息：景点介绍、开放时间、门票、地址、电话、游玩时长、季节和特色标签。
- 旅行指南：路线、交通、住宿、美食和出行建议。
- 懒人攻略：点点生成的结构化实用攻略，不得用旅行指南模板冒充。

### 必须继承

- 高德优先负责实体、地址、坐标、电话、评分和官方图片。
- 景区官方与公开百科用于事实补证。
- 点点负责更适合人阅读的攻略内容，但不得覆盖已确认的事实字段。
- 修复前必须先判断错误属于哪一层，禁止把一种内容写入另一层。

## 2026-08-25｜全国美食列表数据流程

### 当前结构

- 美食数据指省市景点列表旁的美食推荐卡片，不是景点弹窗内的美食段落。
- 总控保持 3 个入口：`补全`、`预览确认`、`写入数据`。
- 全国任务一次运行，按省、市归属整理；无法精确到市的才进入“其他”。

### 数据来源与边界

- 名称和地域：存量旅行指南、地方公开资料及城市归属统计。
- 图片：优先稳定公开图源并进行名称、实物、尺寸和连通检查。
- 描述与标签：优先复用真实存量与公开事实；禁止模板套话冒充采集结果。
- 评分：只有明确公开评分来源时才展示，禁止按提及次数伪造平台评分。
- 写入前必须跨地区、跨品类抽测；个别失败保留断点，不阻断全国批次。
