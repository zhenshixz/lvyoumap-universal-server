## 2026-09-07｜隔离预览按钮失效根因修复

- 现象：图库地图隔离预览中，PC端“查看大图”和详情右上角关闭按钮均无响应。
- 根因：构建及预览脚本使用全局 `app.js` 字符串替换缓存版本号，误命中 HTML 内“由 app.js 动态生成”等注释，并吞掉直到下一处引号之间的HTML，造成DOM结构损坏和事件初始化中断。
- 全局修复：`scripts/build.js` 只允许在 `src="app.js"`、`src="china_geo.js"`、`href="style.css"` 属性内替换版本；图库预览脚本同样只替换脚本 `src`，以后页面正文和注释出现文件名也不会被破坏。
- 已重新原子构建 beta 并重建52个景点隔离预览。PC自动化验证：大图打开、大图关闭、详情关闭全部成功；手机390×844触屏环境验证：切换至2/5、大图打开和关闭成功；浏览器运行错误为0。

## 2026-09-07｜图库断点恢复、稳定来源提速与实图初审

### 当前结果与边界

- 仅在 beta 工作，未修改正式 Git、未写入地图图库、未部署；Gemini 文档和前端修改未动。
- 当前仍是跨省 **100 个样本**，不是全国完成。达到 5 张候选图的景点由 20 个增加至 **52 个**，另 **48 个**保留断点。候选暂存 `.runtime/attraction-gallery-batch/state.json`，9 张联系表在该目录的 `contact-sheets` 下。
- 已浏览全部联系表，并新增拒绝 11 个 URL，涉及海报、叠加水印/宣传标识、拼贴与疑似异地图片。拒绝清单累计 12 项。长隆、香港迪士尼、德天等不能为凑数放行。
- `ready_for_user_review` 只表示有 5 张可供进一步验收的候选，不代表逐图原尺寸、真实手机外链加载及实体真实性全部通过。联系表初审不能代替最终地图验收；不得直接全量写入。

### 根因与修复

- 携程旧逻辑泛抓 `imageUrl`、截前两张，容易混入非相册内容。改为解析 `__NEXT_DATA__ → poiDetail → imageInfo.poiPhotoImageList`，核对实体名称，记录页面、POI 和图片 ID；不扫评论、相关推荐图片。
- 省份列表的 `?keyword=` 未形成有效筛选。改为最多 3 页实际列表，复用历史携程/二次补证链接；同页并发请求合并、HTML 缓存 7 天，避免各景点反复下载同一页。
- 备用源触发改为按已通过尺寸检查的图片数，不再按原始链接数量。只对未完成景点执行，有少量候选余量供去重，不重跑已完成图库。
- BAT 与 npm 入口加入 `--repair-pending`；改变批量大小不清空状态，`--max-items` 可限定本轮工作量；按旧断点优先续跑，单项异常不终止整批。
- 状态采用临时文件原子替换；审图文件改用内容哈希命名，恢复时校验哈希，避免旧索引文件被覆盖后显示错图。保留成功的高德缓存；此前未成功取得高德数据的记录允许以后重试。
- 修正 dHash 行索引；保留已筛选结果，记录近似重复/过暗/解码失败原因；命中拒绝清单会重新筛选。
- BAT 保持 ASCII + CRLF，增加路径、脚本及 Python 图片依赖预检，错误保留窗口。
